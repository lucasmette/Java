# Linguagens de programção
## 1. Java
  Java é uma liguagem muito versátil, que utliza POO, isso faz om que o código seja muito reutilizavel.
## 2. JavaScript
   JavaScritp é uma linguagem de programação que adiciona dinamismo, inteligência e interatividade a páginas web.
## 3. HTML
  HTML é a linguagem padrão utilizada para criar e estruturar páginas na web, ou seja, cuida de tudo o que é escrito dentro de um site.
## 4. CSS 
  CSS é uma linguagem de estilo usada para definir a aparência visual de páginas web, controlando cores, fontes, layouts e espaçamentos.
